🛰️ OrbitCare — Astronaut Health Monitoring Wearable

OrbitCare is an integrated wearable smartwatch and telemetry ecosystem developed for the NASA Space Apps Challenge. It monitors biometric and environmental parameters in real time, computes individual astronaut physiological baselines, detects anomalous deviations from normal patterns, and visualizes mission data across a mobile crew application and a mission control dashboard.

📌 System Architecture

        MPU[MPU6500 IMU Motion Sensor] --> ESP
        DHT[DHT11 Temperature & Humidity] --> ESP
        BTN[Tactile Calibration Button] --> ESP
        ESP --> OLED[SSD1306 OLED Display]

    subgraph DataEngine [Data Storage & Analytics]
        API --> DB[(SQLite Database)]
        DB --> DE[Data Engine Adapter]
    end

    subgraph Clients [Synchronized Client Interfaces]
        API -- "REST API (/status, /readings)" --> APP[React Native / Expo Mobile App]
        DE --> DASH[Streamlit Mission Control Dashboard]
    end

🚀 Quick Start Guide

1. Smartwatch Firmware (ESP32-C3)

  1. Open firmware/OrbitCare_firmware/OrbitCare_firmware.ino in Arduino IDE.
  2. Install required libraries via Library Manager:
    • MAX30100lib by OXullo Intersecans
    • Adafruit SSD1306 & Adafruit GFX Library
    • DHT sensor library by Adafruit
  3. Update your local Wi-Fi SSID, password, and laptop IP: 
    const char* WIFI_SSID     = "YourHotspotName";
const char* WIFI_PASSWORD = "YourPassword";
const char* API_URL       = "http://YOUR_LAPTOP_IP:8000/readings";
  4. Select board ESP32C3 Dev Module and upload.

2. FastAPI Backend

In your terminal, navigate to the project root and run:

python -m venv .venv
source .venv/bin/activate   # On Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m uvicorn api:app --host 0.0.0.0 --port 8000 --reload

Endpoints:

  • POST /readings — Ingest telemetry from ESP32.
  • GET /status — Device connectivity, last seen age, and latest reading.
  • GET /readings?limit=50 — Historical telemetry records.
  • GET /baseline — Latest stored personal baseline.

3. Streamlit Mission Control Dashboard

In a separate terminal, launch the presentation dashboard:

streamlit run app.py

Open http://localhost:8501 to view real-time charts, sensor diagnostics, and export mission logs.

4. React Native Mobile App (Expo)

In the mobile/ directory:

cd mobile
npm install
npx expo start --lan

Scan the QR code with Expo Go on your smartphone connected to the same network.

🔬 Core Innovations

  1. Personal Physiological Baseline (Non-Volatile Storage): Rather than using generic one-size-fits-all clinical thresholds, astronauts calibrate their personal resting baseline via a 3-second button press. The baseline is stored in the ESP32's non-volatile NVS flash memory.
  2. Explainable Anomaly Flags: Rule-based flags explicitly justify deviations (e.g. “Heart rate is 18 BPM above baseline; tolerance is ±15 BPM”) instead of providing opaque black-box AI outputs.
  3. Dual-Mode Data Engine: The dashboard and mobile application seamlessly toggle between live hardware telemetry and simulated space flight emergency scenarios (hypoxia, tachycardia, low activity).
  4. Decoupled FreeRTOS Architecture: Sensor sampling runs on dedicated non-blocking loops, while network transmissions execute within an isolated FreeRTOS task to prevent Wi-Fi latency from interrupting optical pulse sampling.

⚠️ Educational Prototype Disclaimer

All sensor readings and alerts produced by OrbitCare are experimental demonstration data. They are not intended for clinical diagnostics or astronaut safety-critical life support.
